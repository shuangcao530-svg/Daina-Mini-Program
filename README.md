# 校速达 - 校园代拿微信小程序原型

这是一个原生微信小程序原型，适合校园代拿业务：快递、外卖、文件、钥匙和其他物品的点对点代拿。

## 已实现

- 用户首页：展示服务入口、流程和核心卖点。
- 发布订单：填写起点、终点、取件码、紧急程度、备注，并强制上传下单前物品图片。
- 我的订单：按全部、待接单、进行中、已完成筛选。
- 订单详情：展示下单图片、工作人员取到图片、送达图片和订单时间线。
- 接单工作台：工作人员可接单、上传取到图片、开始配送、上传送达图片并完成订单。

## 建议继续扩展

- 登录与角色：区分普通用户、工作人员、管理员。
- 后端接口：把当前 `app.js` 中的本地模拟订单换成云开发数据库或自建 API。
- 支付和退款：接入微信支付，支持超时取消、异常申诉、平台仲裁。
- 校园地图：维护常用地点、楼栋、宿舍区，减少用户输入成本。
- 工作人员风控：实名认证、学生认证、接单上限、保证金、评价体系。
- 隐私保护：取件码和手机号仅对接单员可见，订单完成后定期脱敏。

## 使用方式

用微信开发者工具导入当前目录，选择“小程序”项目即可预览。
